# Паводок в Бангкоке: генератор страницы

Страница: [`public/bangkok-flood/index.html`](../../public/bangkok-flood/index.html). Это один самодостаточный HTML-файл: его можно открыть в браузере или отдать с любого статического хостинга. В dev-режиме сайта (`pnpm dev`) он доступен по адресу `/bangkok-flood/index.html`.

Карта показывает 50 районов Бангкока с 20 сентября по 25 октября 2026 года. До 26.09 — факт по сводкам, дальше — ансамблевый прогноз. Ползунок меняет карту, осадки, прилив в устье и оценку уровня Чао Прайи.

## Как пересобрать

```bash
pip install shapely numpy utide
python3 fetch_inputs.py   # OSM, geoBoundaries, Open-Meteo: 6 ансамблей, 9 моделей, SEAS5, ERA5, GloFAS, уровень моря
python3 fetch_obs.py      # ThaiWater (дождемеры, каналы, река, плотины), TMD (прогноз, наблюдения), METAR
python3 model.py          # 221 сценарий x 50 районов -> data/model_out.json, carry.json
python3 build.py          # -> public/bangkok-flood/index.html
```

Страница обновляется каждые 4 часа. «Сегодня» — это дата последних наблюдений (`fetch_obs.py`). Новый день начинается с состояния, на котором закончил последний прогон вчера: `model.py` пишет его в `carry.json`, файл коммитится вместе со страницей. Там же хранятся суточные суммы дождемеров за прошлые дни.

Утренняя сводка задаётся руками:

- `obs.py`: `OBS_DATE` и `OBS_LEVEL` — уровни воды по районам на это утро. Если сводка ставит район на другой уровень, чем перенесённое состояние, верх берёт сводка;
- `content.py`: тексты (сводка, недели, советы) и `NEWS_AT` — время сводки.

## Как считается

| Шаг | Что делаем |
|---|---|
| Дождь | Взвешенный суперансамбль в 6 точках города: ECMWF ENS (51), ECMWF AIFS ENS (51), NOAA GEFS (31), GEPS (21), ICON-EPS (40), MOGREPS-G (18) и 9 детерминированных моделей (ECMWF HRES, AIFS, GFS, ICON, JMA, GEM, ARPEGE, UKMO, CMA). После горизонта модели сценарий продолжают GEFS/GEPS, ECMWF SEAS5 и аналоги ERA5 1991–2025 (норма 288,7 мм за октябрь, −15% из-за Эль-Ниньо). |
| Факт | Дождемеры ThaiWater: около 130 работающих станций BMA, HII и TMD в Бангкоке. Станции, которые давно молчат, отброшены. Сутки у дождемеров идут с 07:00 до 07:00: суммы прошлых дней заменяют модельные, а сегодня = выпавшее с 07:00 + прогноз на часы до полуночи. |
| Район | Модель «ведра»: сток зависит от насыщенности почвы. Откачка идёт со скоростью, оценённой для каждого района (`districts_static.py`), и замедляется в сильный прилив и при переполненных каналах. Для окраин учтён приток с полей. |
| Старт | Утро 27.09 — по сводкам BMA, DDPM и СМИ (`obs.py`). Дальше каждый день начинается с конца предыдущего (`carry.json`), утренние сводки его поправляют. Осадки 24–26.09 подогнаны под станционные суммы. |
| Прилив | Гармонический анализ (utide) уровня моря в устье по данным Copernicus/Open-Meteo плюс сезонный подъём уровня залива. |
| Река | Тренд GloFAS, привязанный к свежему расходу ниже плотины Чао Прайя (ThaiWater, станция C.13). |
| Сценарии | 10-й, 50-й и 90-й процентили по 221 сценарию; вероятность — доля сценариев с водой на улицах (10+ см). |

Это оценка, а не официальный прогноз. Отдельную грозу модель не предсказывает: 100 мм за пару часов зальют улицы в любом районе.
