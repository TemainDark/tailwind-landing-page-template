# Паводок в Бангкоке: генератор страницы

Страница: [`public/bangkok-flood/index.html`](../../public/bangkok-flood/index.html). Это один самодостаточный HTML-файл: его можно открыть в браузере или отдать с любого статического хостинга. В dev-режиме сайта (`pnpm dev`) он доступен по адресу `/bangkok-flood/index.html`.

Карта показывает 50 районов Бангкока с 20 сентября по 25 октября 2026 года. До 26.09 — факт по сводкам, дальше — ансамблевый прогноз. Ползунок меняет карту, осадки, прилив в устье и оценку уровня Чао Прайи.

## Как пересобрать

```bash
pip install shapely numpy utide
python3 fetch_inputs.py   # OSM, geoBoundaries, Open-Meteo -> ./data (5–10 минут, Overpass медленный)
python3 model.py          # 154 сценария x 50 районов -> data/model_out.json
python3 build.py          # -> public/bangkok-flood/index.html
```

Снимок от 26.09.2026 собран из данных, скачанных утром 26.09 (UTC). При повторном запуске прогнозы будут новее. Перед пересборкой на другую дату обнови:

- `obs.py`: уровни воды по районам по свежим сводкам, суммы осадков, расход реки;
- даты `START`, `TODAY` и `END` в `model.py`;
- тексты в `content.py`: сводку, недели, советы.

## Как считается

| Шаг | Что делаем |
|---|---|
| Дождь | Ансамбли ECMWF IFS (51), ECMWF AIFS (51), NOAA GEFS (31) и GEPS (21) в 6 точках города. После 10-го дня их постепенно заменяют аналоги из ERA5 1991–2025, приведённые к норме станции (288,7 мм за октябрь) и уменьшенные на 15% из-за прогноза сухого октября при Эль-Ниньо. |
| Район | Модель «ведра»: сток зависит от насыщенности почвы. Откачка идёт со скоростью, оценённой для каждого района (`districts_static.py`), и замедляется в сильный прилив и при переполненных каналах. Для окраин учтён приток с полей. |
| Старт | Состояние утром 26.09 по сводкам BMA, DDPM и СМИ (`obs.py`). Осадки 24–25.09 подогнаны под станционные суммы. |
| Прилив | Гармонический анализ (utide) уровня моря в устье по данным Copernicus/Open-Meteo плюс сезонный подъём уровня залива. |
| Река | Тренд GloFAS, привязанный к фактическим 1 900–1 950 м³/с и лимиту сброса плотины 2 000 м³/с. |
| Сценарии | 10-й, 50-й и 90-й процентили по 154 сценариям; вероятность — доля сценариев с водой на улицах (10+ см). |

Это оценка, а не официальный прогноз. Отдельную грозу модель не предсказывает: 100 мм за пару часов зальют улицы в любом районе.
